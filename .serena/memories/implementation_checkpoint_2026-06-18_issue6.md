## 最重要の横断知見：Node.js 24 系ではビルドが異常終了する

- **症状**: `npm run build` の本番ビルドが、変換完了後のチャンク生成段階で異常終了する（終了コード `-1073740791` ＝ `0xC0000409`。JavaScript の例外でもメモリ不足でもないネイティブの異常終了で、Node の致命的障害レポートも出ない）。
- **根本原因（判断根拠を先に述べる。原因の特定には変える条件を1つに絞るのが妥当なため、依存を一切変えず Node の版だけを 24 から 22 に変更したところビルドが正常完了した）**: Node.js 24.13.0 とビルド工具（Vite 5.4 系およびそれが用いる Rollup）の非互換。Vite 5.4 系・Vite 7.3 系、Rollup のネイティブ版・WebAssembly 版のいずれでも Node 24 系で再現し、Node 22 系では正常完了する。
- **解決（リポジトリ側）**: `package.json` の engines に `^20.19.0 || ^22.12.0` を追加（Vite 5.4 系が対応し、かつ異常終了する Node 24 系を除外する版として 20 系と 22 系を採用）、`.nvmrc` に `22` を記載、`README.md` に Node の要件と理由を明記。依存構成は当初どおり（Vite 5.4.21・Rollup 4.61.1・overrides なし）。
- **開発環境側（この端末）**: `fnm`（Fast Node Manager）を導入し Node 22 系を既定化、PowerShell プロファイルに fnm の `.nvmrc` 自動切替フックを設定済み。**ビルドは Node 20 系または 22 系で行うこと。**
- **後続への申し送り**: Issue #7（GitHub Pages 配信のCI）では、CI のワークフローで Node 22 系を固定するか `.nvmrc` を使うこと。
