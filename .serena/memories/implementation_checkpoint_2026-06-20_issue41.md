## 採用した数値とその理由（すべて理由を先に述べる）

- 合成格子の刻み = 1000ミリ秒: 歌詞密度は単位時間あたりの文字数として自然に数えられ、TAKEOVER は平均毎秒約8.3文字なので1秒ビンでも疎にならない。声量も同じ格子へ平均で揃え2信号を同じ点で足す。
- 声量の再標本化は平均（最大でない）かつ無音センチネル −1 を0として分母に算入: 平均は1秒間の持続的な声量を表す。最大値だと単発の突出に引きずられ後段の平滑化と矛盾する。無音は実在する時間で盛り上がりが無いことを意味するので0として算入し声量を正しく引き下げる。曲末の半端なビンは実サンプル数で割る（理論個数だと実在しないサンプルを0と数え値が下がる）。
- 平滑化の片側ビン数 = 2（前後計5秒）: 見せ場は数十秒の区間（chorus 約22秒）で、最短の構造区間より十分短い5秒窓なら区間どうしをぼかさず一過性の突出だけを除去できる。
- 正規化は自身の最大値で割る（百分位でない）: 平滑化の後に正規化するので最大値は瞬間値でなく持続水準を表し、百分位での頑健化は不要。単位の異なる声量と歌詞密度を[0,1]へ揃え同等の影響度で足す。
- 合成の重み = 声量0.5・歌詞密度0.5: §3.6 が両者を並列に挙げ優先度を定めていないため中立な等配分とする。
- climax ガード幅 = 8000ミリ秒（両端含む）: climax 自身のエネルギーの裾を別の見せ場に数えないため。非chorus窓の片側幅（毎分175拍で約5500ミリ秒）を上回るので climax のすぐ外側の窓が climax と重ならない。TAKEOVER ではおよそ193秒の候補がこれで除外される。
- 非chorusピークの最小間隔 = 20000ミリ秒: 見せ場6個が約237秒に対し平均約40秒間隔になるので、その半分以上離せば同一の盛り上がりに2つの見せ場が重ならない。実データの約38秒間隔（25秒と63秒、63秒と138秒）は許容される。
- 非chorus窓の片側拍数 = 16拍（拍が使えなければ片側5500ミリ秒）: 16拍は4分の4拍子で4小節、毎分175拍で約11秒となり chorus 区間（約22秒）の半分に相当する一貫した投下窓の長さになる。代替の5500ミリ秒は毎分175拍での16拍に相当する。
- 最小窓長 = 2000ミリ秒: `validateProfile` は開始が終了より前であることしか見ないため、投下の対象として知覚できる最小限を下限に置き、これを割る切り詰め結果は退化入力として失敗させる。最小間隔20000ミリ秒が非chorus窓の全幅（約11000ミリ秒）を上回るので片側だけの切り詰めとなり通常は約5500ミリ秒が残るため、このエラーは防御目的で正常入力では発火しない。
- 重みの値域 = climax 1.0固定・非climax [0.4, 0.9]: climax を1.0に固定し他を0.9で頭打ちにすればデータに関わらず climax が厳密に最大になる。投下倍率は重みに比例するため重みがほぼ0だと投下の価値が消え見せ場の意味と矛盾するので下限を0.4とする。
- 重み同値とみなす差の上限 = 1e-9（重み写像のみ。貪欲選択の同点は厳密比較）: 合成値は有限和の正規化で得るので差が1e-9未満は数値誤差の範囲で実質同値とし、線形写像のゼロ除算を避けて中点0.65を割り当てる。貪欲選択に許容差を使うと最大値近傍の別の山を同点と誤認しうるため選択は厳密比較とする。
- 信頼比の目安下限 = 0.6（診断値であり選定を止めるゲートではない）: 実データで非chorusの盛り上がり（0.82〜0.86）と谷（約0.3）を分ける目安。0.6未満でも生成は成功させ、TAKEOVER の達成基準としてのみテストで強制する。生成ロジックはこの値を参照しない。

## レビューと検証（事実）

- 計画段階で Codex のレビューを4巡反映: 189秒 climax が窓に含まれるよう終端を延長、約193秒を除く climax ガード帯、声量再標本化を平均と明記、chorus 窓を不変とし非chorus窓のみ切り詰め、重み写像の同値時ゼロ除算回避、ビン代表時刻をビン中心に統一、chorus 由来 climax の曲長ガード、非chorus窓重なり解消を左から右への決定論的順序、信頼比の出力契約を専用関数に分離、横展開での `climaxAnchorMs` 供給責務を #45 に明示。
