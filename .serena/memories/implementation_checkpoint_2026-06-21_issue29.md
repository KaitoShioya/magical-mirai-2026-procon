## 位置づけ

マイルストーンM3「キネティックタイポグラフィエンジン」の中核機構。歌詞の発声属性に応じて、文字・単語・フレーズ・画面全体の4段の表示粒度を時間軸で切り替える曲非依存の純粋ロジックを提供する。出力（表示粒度プラン）は演出割付規則（#132）と曲固有譜面（#33）が消費し、表示同期ゲート（#99）が検査の対象とする。

## 最重要の意思決定（Codexによるレビュー3回を反映して確定）

- **表示粒度は4段とする**: 正典 concept-final §11 が「文字・単語・フレーズ・画面全体」の4段と明記するため、第5の粒度を新設しない。#33 の受け入れ基準「長いフレーズは単語単位または分割したフレーズへ落とす」が要求する分割は、フレーズ粒度の中の「チャンク分割」という配置操作（出力フィールド `phraseChunk`）で満たす。粒度の値の集合は4つだけ。
- **責務の境界**: #29 は「粒度」と「判定理由（`reason`）」までを出力する。具体的な演出効果（縦伸ばし・円状回転・段階的構築・強調など）への写像は #132 が行う。#29 は演出効果の名前を出力に持たない。これにより #132 が素通しにならない。
- **完全に決定的（事前計算）**: 読み込み時に、確定済みデータ（歌詞タイムライン・ビート格子・声量曲線・区間境界・曲の終了時刻）だけから一度計算する。再生中の声量の瞬時値には依存しない（瞬時値は演出細部 #30 の領域）。
- **歌詞型は純粋モジュールから型のみ取り込む**: `LyricsTimeline` ほかを `src/textalive/lyricsTimeline.ts` から `import type` で直接取り込む。公開窓口 `src/textalive/index.ts` は再生実装（textaliveパッケージ依存）を再輸出するため経由しない。ビート格子・声量・区間境界は profiles を import せずローカル構造型で受け取る。three は import しない。

## 採用した数値とその理由（実データTAKEOVERで裏取り）

- 短音上限150ミリ秒・長音下限500ミリ秒: song-insights.md が短音率・長音率をこの境界で3曲比較しているため揃える。
- 短音優勢比率0.5・長音主体比率0.5: 多数決で発声性格を判断する。長音を1文字でも含めば長音主体とすると、継続時間最長フレーズ「NaNaNaNa」（8文字・長音1文字・短音率0.75・文字密度0.27）を誤分類するため、多数決にする。実装結果として「NaNaNaNa」は短音優勢かつ低密度の文字粒度になる。
- 間引き文字密度閾値1.0字/拍: 1拍あたり1文字を超えると毎拍に1文字を割り当てられないため、研究資料の「2拍に1回へ間引き」を発火させる。文字数最多フレーズ「アップ＆ダウン…グランブルー」（33文字・密度2.2）は長尺かつ高密度のフレーズ流し込みになる。
- 高声量比率0.6: 声量の絶対値は曲依存のため曲の最大声量への比率で判断する。
- 一画面可読文字数14: 最小表示寸法の文字を横一列で画面に収まる見積もり。#31 の最小表示寸法確定後に再調整する。
- 近接反復の時間窓8000ミリ秒: 実データで近接反復は「ClaptotheBeat」「Noise＆Hits」各4回（前後3フレーズ以内）のみ。遠く離れた再登場（前後32フレーズ以上）は連発でないため、時間窓で限定する。
- 無音を画面全体にする最小拍数2拍・ビート吸着許容は半拍（隣接ビートの中点で帰属を一意化）。

## PRレビュー（Codex）反映

PR #145 に対する Codex のレビューで妥当と判断した指摘を反映した。
- ビート吸着の衝突でセグメントを捨てると内容が消えるため、前の開始より後の最初のビートへ置き直すフォールバックを追加（置けるビートが無い場合のみ除去）。
- 最大声量が0のとき「声量が大きい」が常に真になり全フレーズを長音主体と誤判定するため、最大声量が正であることを前提条件に加えた。
- 文字を持たないフレーズはセグメントを作らないガードを追加した。
- フレーズが時刻昇順であることを使い、近接反復の判定を隣接出現の対のみで線形に行うよう変更した（二重ループの解消）。
- セグメント時刻が表示の切替（ビート吸着後）であり発声時刻と一致しないこと、文字発火間隔が発火あたり文字数でないこと、長尺高密度を分割しないこと、1単語が可読数を超える場合の扱いを、型コメントとREADMEに明記した。
- 追加テスト: 吸着衝突時の非脱落、最大声量0での非長音主体、文字0フレーズの非生成。
