## 最重要の意思決定（採用理由を先に述べる）

- **倍音の周波数は基本周波数の2倍の正弦波**。協和を崩さないため倍音は基本周波数の整数倍にする（整数倍は倍音列の一員で協和する）。整数倍のうち2倍は周波数比2対1（1オクターブ上）で最も協和度が高い。基本音の波形は三角波で奇数次倍音のみを含み2倍成分を欠くため、2倍を足すと既存成分の増強でなく新しい成分が加わり、音程を変えずに音色が豊かになる。波形を正弦波にする理由は、Issue文言「倍音層を1つ追加」を厳密に満たすのは単一成分の正弦波であり、三角波で2倍音を作ると2倍・6倍・10倍の複数成分が加わって語義から外れるため。診断2和音の全音高（65・68・72・75・77・79・80・84・87）で2倍周波数は最大約2489ヘルツであり、低域通過の遮断4500ヘルツを下回るため可聴。`SYNTH_OVERTONE_RATIO`=2 を ★暫定 で `synthConstants.ts` に置く（音色設計上の初期選択で、実機試聴で第3倍音などへ変える余地があるため）。
- **倍音の音量比は基本音の0.35倍**。倍音は音程を定める基本音に従属する補助のため1未満にする。明るさ・手応えとして聞こえる必要があるため基本音のおよそ3分の1（線形0.35、約マイナス9デシベル）にする。倍音込みの瞬間最大振幅は基本頂点0.5×(1＋0.35)＝0.675が上限で、動的圧縮（閾値マイナス6デシベル）とマスター音量0.3で飽和しない。`SYNTH_OVERTONE_GAIN_RATIO`=0.35 を ★暫定 で置く。実機試聴で「明るく・厚く、音程不変、濁りなし」と良好と判断し調整不要とした。
- **倍音は基本音と同じ音量包絡を共有する**。「重ねる」とは同一の発音イベントに成分を足すことであるため、倍音オシレーターを一定比率の倍音音量節点を介して基本音の包絡を持つ音量節点へ合流させ、立ち上がり・減衰を完全に一致させて別の立ち上がり雑音を出さない。
- **外部制御口は状態切替 `setDeployTimbre(active: boolean)`**。依存規則（audio は scoring・profiles を import しない）に従い、投下の状態は呼び出し側が真偽値で渡す。投下を時間幅の状態として扱う仕様と一致する。既定は偽、破棄後は発音が無音のため無作用。#59 が投下の開始で真、投下窓の終了で偽へ同期させる契約を README に明記。
- **投下中に新しく鳴らす音にのみ倍音を重ね、すでに鳴っている音は遡って書き換えない**。仕様は投下を時間幅を持つ状態として描く。すでに鳴っている音の予約済み包絡を実行中に書き換えると切れ目の雑音が出る危険があり、減衰は200ミリ秒で短く遡及の利得はほとんど聞こえない。
- **明るさは周波数重心で測り、投下時が通常時の1.05倍を超えることを基準にする**。周波数重心は各周波数成分を振幅で加重平均した周波数であり音色の明るさに対応する標準指標である。三角波の奇数次倍音の振幅は次数の2乗に反比例し、基本周波数を単位として通常時の重心は約1.43倍、2倍の正弦波を振幅0.35で足すと約1.56倍となり上昇率は約9パーセント。基準1.05倍は見積もりの約9パーセントより十分低く、測定・数値計算の誤差より十分高い余裕として採る。
- **明るさ測定の固定音量は0.25**。動的圧縮は非線形で重心を変え得るが、測定音量を圧縮の閾値（マイナス6デシベル、線形で約0.5）未満に保てば圧縮は不動作（素通り）になり、重心を形作るのは高域通過・低域通過だけになる。投下時の倍音込み瞬間最大は0.25×1.35＝0.3375で約0.5を約0.16の余裕で下回るため0.25を採る。固定音量は測定専用のため診断ページの局所定数に置く（音色調整値ではないため `synthConstants.ts` には置かない）。
- **`dispose` で voice pool も空にする**。発音数のgetter（`soundingVoiceCount`・`activeVoiceCount`）はプール由来のため、破棄で `voices` だけ空にしてプールを残すと破棄後も発音数を過大報告する。`VoicePool.clear` を追加し `dispose` で呼んで破棄後0にする。
