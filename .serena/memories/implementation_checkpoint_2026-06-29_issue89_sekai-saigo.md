# 実装チェックポイント 2026-06-29 Issue #89 世界最後の音楽隊 横展開

## 成果
課題曲「世界最後の音楽隊」（作者 夏山よつぎ×ど～ぱみん、曲キー sekai-saigo、曲長249600ミリ秒）を実装済み曲にした。題名画面から選んで通しプレイ・採点・結果表示・成果物画像生成まで成立する。ブランチ issue-89-sekai-saigo-yokoten、PR #224。作業中に こたえて（Issue #90、PR #222）が main にマージされ本曲が6曲目となったため、これで課題曲6曲すべてが実装済みになった（準備中の曲は無い）。

## main統合（こたえて #90 との競合解消）
作業中に main がこたえて横展開（PR #222）を取り込んだ。競合はすべて「曲を1つ各リストへ追加する」加算的なもので、こたえてと本曲の両方を残す形で解消した。対象は曲束 index.ts・生成コマンド・スキーマ検査ゲートと同テスト・実装済み集合テスト・画面スモーク。画面スモークは課題曲6曲すべてが実装済みになったため「開始6曲・準備中0曲」に更新した。
歌詞重なり修復の許容合わせ（重要）: こたえては前の文字を1ミリ秒またぐ箇所が2つある。検証関数は許容（1ミリ秒）内のまたぎを認めるため、こたえての生成物は修復前から検証を通っていた。当初の修復は許容を持たず、この1ミリ秒のまたぎも動かしてこたえての生成物を変えてしまった。そこで修復の発火条件を検証の不合格条件（許容を超えるまたぎ）に一致させ、許容内のまたぎには手を加えないようにした。これでこたえての生成物は1ビットも変わらず、本曲の約235ミリ秒のまたぎだけが直る。

## main方式の採用（結線は無改造）
mainは既にloadSong方式の多曲選択（同一プレイヤーで別曲を再ロードし、曲依存オブジェクトを差し替える）と曲束レジストリ src/profiles/index.ts の songBundle(key) を備える。このため app・main・screens の結線改変は不要で、曲束へ登録するだけで選択と通しプレイが成立した。当初プランの起動時選択方式（registry.ts新設・main.ts・screens改変）は採用していない。

## 歌詞文字の時刻重なり修復（共有アダプタへ追加）
本曲は同時発声の2文字が同一開始時刻・終了時刻のまたぎで返る箇所が1つあり（文字索引258）、検証関数validateProfileの「歌詞文字は開始昇順かつ前文字の終了をまたがない」要求に落ちていた。src/profiles/generate/songmapAdapters.ts の toLyricChars に前向き走査の修復を足した。直前までの最大終了時刻を保ち、開始がそれより前なら開始を繰り上げ、終了が開始より前なら終了を開始へ繰り上げる。修復を最小移動にした理由は、重なりの無い入力には一切手を加えず（出力が入力と一致）、既出荷4曲の生成物を不変に保つためである。実測で4曲とも重なり0件、本曲のみ1件であることを確認した。

## 非対称サビでの多様性逓減（専用機能は不要と判断）
本曲はサビが2区間で拍数が非対称（第1サビ34拍・最終サビ66拍）である。mainの共有テンプレート方式は全サビに共通する最小拍数の範囲でテンプレートを作り各サビへ写すため、最終サビのノーツが第1サビと同じ拍オフセットに揃う。結果、第2サビのノーツ17件すべてが第1サビと同じ拍オフセットで重なり、多様性逓減が完全に機能する。クライマックス代表時刻もこの共通範囲に入り被覆される。最小拍数を超える最終サビ後半はノーツが薄くなるが、これは同じ拍数比のアフター・ザ・カーテン（既出荷）と同じ扱いであり、専用の譜面機能追加は不要と判断した。

## 曲固有値の導出
- musicalKey=ト長調（主音の音名クラス7、長調）。調の値は無和音区間を音階で埋めるときだけ使われる。本曲の無和音区間8個のうち曲頭の索引0（直前和音が無い）だけが調の音階に倒れ、残り7区間は直前に実在和音が隣接するため直前和音を保持する。前半の和音頻度がト長調の音域のため曲頭区間の解決はト長調が正しい。後半はヘ長調へ転調するが後半の無和音区間は音階を使わないため単一の調をト長調にしても破綻しない。生成物のncRangesがscale1個・previous7個であることで固定。
- climaxAnchorMs=191600。最終サビ区間（185576から211750ミリ秒）の声量曲線が最大になる時刻を感情のピークの代表時刻とした。
- camera=曲長と2サビ・クライマックスに節目を置く6点を専用設計（ユーザー確定方針＝カメラ軌跡のみ専用、色・操作音・多様性ラベルは流用）。全時刻で軌跡上速度が正であることをテストで固定。
