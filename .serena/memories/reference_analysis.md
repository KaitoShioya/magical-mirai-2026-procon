# 参考演出3素材の解析結果（2026-06-13）

詳細な全文は `docs/idea/reference-analysis.md`（リポジトリ内）。ここは要点のみ。

## 1. テキスト表現リファレンス（docs/idea/DXW0aT6FKSlkqBq2.mp4, 11秒）

メンタルチェーンソー題材のキネティックタイポ。音声解析 ≈184.6 BPM。
**核心: 「い」「た」「れ」の1文字スマッシュカットが連続ビート時刻に正確一致（1文字=1拍の厳密同期）**。疾走感は感覚ではなく同期設計の産物。

設計文法（リリック属性→表現のマッピング）:
- 強い口調・スタッカート → 1文字1拍スマッシュカット（`IChar`+`findBeat`）
- 流れる連続フレーズ → 全文一括表示+字間広げ+数拍ホールド（`IPhrase`）
- 同一フレーズの連発 → 円状配置+回転フォーカス or 一点重ね増殖
- ロングトーン/シャウト → 文字の縦引き延ばし・渦/円状エフェクト（`getVocalAmplitude`）
- 曲の切れ目 → ブラックアウト句読点
- その他: スケールの暴力（文字が画面を覆う/文字内をカメラ通過）、多重残像エコー、色アクセント最小運用（基調2色+強調語のみ赤）、背景は強ボカシ写真

## 2. シャッターチャンス公式MV（YouTube ZVGbTFcfnn8, 3:10, ≈117.5 BPM）

- 配色: パステル青×黄（#AEC6F0/#FBE6A2系）+白フチ、ピンク♡アクセント
- モチーフ: 指フレーム、円形レンズマスク、ポラロイド/写真カード、SNSフィード、カメラUI（REC・フォーカス十字）、紙吹雪/破片トランジション
- タイポ2系統: Aメロ=細い縦組み手書き風（静）/ サビ=極太+白フチ+蛍光色の段スタック（動）
- 最大の山（2:30-2:34）: 写真タイル増殖→カメラREC UI→モザイク→ドン、の「撮影完了の儀式」
- ループ構造（アウトロが冒頭の決めポーズに回帰）
- 応用候補: クリック=シャッター（フラッシュ+歌詞が写真カード化してスタック→曲末にアルバム化）、「ピント」=モザイク→解像の文字演出

## 3. the hole / r-906（YouTube qe29NgNqJZw, 3:56, ≈117.5 BPM）

- 白×黒線ミニマル2色+クライマックスのみ赤/オレンジ差し色
- **1音1カット級の音ハメ**（サンプル明細: ビーム.wav×310, 心音×104, シンバル×56）が「付加的音楽表現」の最重要参考
- 技法: 強拍フルスクリーン極太タイポ、句読点ブラックフレーム、縦スプリット○✕対比、複製タイリング明滅、疑似UI（偽ニュース速報）、文字グリッチ
- Webアプリ応用は実装難度付きで docs/idea/reference-analysis.md §3.2 に10案

## 横断知見

1. 疾走感=「1拍単位で必ず何かが動く」+ 粒度（文字/単語/フレーズ/画面）を数拍ごとに切替えて単調回避
2. シャッターチャンス(115-117.5 BPM)とthe holeは同テンポ帯 → 音ハメ文法を直輸入可能
3. 色は2色基調+差し色1色が3素材共通
4. AI素材なしでも (a)グリフ変形 (b)図形記号 (c)自作疑似UI (d)強ボカシ背景 で画面はリッチにできる
