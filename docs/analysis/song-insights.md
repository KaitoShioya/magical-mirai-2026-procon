## 曲別の構造的特徴

### シャッターチャンス（115 BPM）
- **サビ区間が10個**と圧倒的に多い。3–19s（冒頭サビ!）、53–86s、155–188s の3ブロック構成。曲頭3秒でいきなりサビ＝**開幕から最高潮の演出が必要**
- 連発フレーズの宝庫: **「いつだってシャッターチャンス」×4回**（3s/53s/136s/155s）、「完全無欠flawless」×3、「今すぐ私に焦点合わせて！」×2 ほか6種 — 参考動画の「円状回転・一点重ね」技法の適用箇所が明確
- スタッカート37%/ロング5%のバランス型。ビート間隔522msは**人間のリズム操作が最も気持ち良い帯域**（やりこみ操作との相性が3曲中最良）
- 歌詞密度ピークは80–90s（サビ後半「切り取り永遠に保存して♡」付近）

### TAKEOVER（175 BPM）
- **すべてが最速・最多**: 文字数1157、スタッカート率55%、密度8.3字/s、フレーズ90個。char p10=19ms（ほぼ知覚限界）
- ビート間隔343msは全拍叩かせる操作は不可能 → 操作させるなら2拍/4拍単位、または**観せる演出（自動疾走）に全振り**する選択肢
- 最長フレーズ30.3拍（ラップ区間）— 文字流し込み系の演出が必須
- 「ClaptotheBeat」×4「Noise&Hits」×4 のコール&レスポンス構造はthe hole式の音ハメと好相性
- arousal 0.47で3曲中最興奮。サビは3区間のみ（1–23s冒頭、89–111s、166–188s）

### 世界最後の音楽隊（150 BPM）
- 3曲中もっとも叙情的（valence 0.16、スタッカート21%、フレーズ長8.2拍）
- サビ2区間のみ（67–94s、186–212s）で、4:10の長尺を構成力で持たせる必要がある
- 連発フレーズは少なく（×2が3種）、会話文（「」）と地の文の描き分けが演出の核になる
- maxVocalAmplitude 59310 は3曲中最大 — 声量ダイナミクスの振れ幅が大きく、`getVocalAmplitude`連動演出が映える
