# 参考演出リサーチ統合解析

ブレスト・設計の基礎資料。3つの参考素材（テキスト表現リファレンス動画 / シャッターチャンス公式MV / the hole MV）の映像解析と音響解析を統合する。

解析手段: claude-video-vision（フレーム抽出・視覚解析）+ mcp-music-analysis（librosa: テンポ/ビート）+ TextAlive songmap（`docs/analysis/*.songmap.json`）。

## 1. テキスト表現リファレンス（docs/idea/DXW0aT6FKSlkqBq2.mp4）

かいりきベア「メンタルチェーンソー」題材のキネティックタイポグラフィ映像。11.1秒、1280x720、30fps。

### 1.1 音響解析

- **テンポ: ≈184.6 BPM（ビート間隔 約325ms）** — 原曲BPMと整合
- 音は約8.5sまで。以降はブラックアウト（映像も8.3s頃から黒）

### 1.2 ビート×映像の同期構造（フレーム解析との突合）

| 時刻(s) | ビート# | 画面 | 技法 |
|---|---|---|---|
| 0.00–1.14 | 1–4 | 「どう転がっても」全文一括表示 | **連続フレーズ=一括表示+文字間隔広げ**。約3–4拍ホールド |
| 1.33–1.67 | 5–6 | 「平」→「平凡」 | 語の段階的構築。背景に強ボカシ写真 |
| 2.00 | 7 | 「凡で」を文字の中をくぐるズーム | カメラが文字を通過するスケール演出 |

| 7.00–8.15 | 22–26 | 渦状の文字歪み→多重残像スタック→輪郭線ゴースト化 | **円状エフェクト**（後述1.3-③）、ワイヤーフレーム化による減衰表現 |
| 8.3以降 | — | ブラックアウト | 曲の切れ目=完全黒の句読点 |

### 1.3 技法カタログ（ユーザー観察による追加を含む）

1. **同一フレーズ連発の表現**: リリック中に同じフレーズが連発される場合、(a) フレーズを**円状に配置し一部分にフォーカスして円を回転**させる、(b) **同じフレーズを一か所に重ねていく**（「イヤ」「嫌」の中央集中+四方増殖が実例）
2. **口調による表示粒度の切替**: 強い口調のフレーズは**1文字ずつ画面全体で高速スマッシュカット**（1文字=1拍でビートに正確同期）。「どう転がっても」のような連続したフレーズは**一度に全文表示しつつ文字間隔を広げる**（数拍ホールド）
3. **歌い方の文字変形への反映**: **文字の縦引き延ばし**（シャウト/ロングトーン）、**円状エフェクト・渦状歪み**（ビブラート・歌い回し）など、発声ニュアンスをグリフ変形で表現
4. スケールの暴力: 漢字1文字を画面からはみ出すまで拡大、文字の中をカメラが通過
5. モーションブラー/多重残像エコー: 回転・移動時に残像を引く（勢いの表現）
6. 色アクセントの最小運用: 基調（黄背景×黒文字）+ 強調語のみ赤
7. 背景写真は終始強ボカシ（雰囲気供給のみ。権利素材を直接見せない手法としても有効）
8. アウトロの減衰表現: 塗り文字→輪郭線ゴースト→消失、最後はブラックアウト

### 1.4 設計文法（リリック属性→表現のマッピング規則）

この映像の疾走感の正体は「**歌詞の発声属性に応じて、表示粒度・スケール・色・変形の4パラメータをビート単位で切り替える**」こと。TextAlive APIへの翻訳:

| リリック属性 | 表現 | TextAlive API |
|---|---|---|
| 強い口調・スタッカート | 1文字1拍スマッシュカット | `IChar` + `findBeat`、`char.duration`が短い箇所 |
| 流れる連続フレーズ | 全文一括+字間広げ+数拍ホールド | `IPhrase` + `phrase.duration` |
| 同一フレーズの連発 | 円状回転 or 一点重ね | フレーズtext重複検出（songmapから事前計算可能） |
| ロングトーン/シャウト | 縦引き延ばし・渦/円エフェクト | `char.duration`が長い箇所 + `getVocalAmplitude` |
| 曲の切れ目 | ブラックアウト | ビート/セグメント境界 |

## 1B. テキスト表現リファレンス2（docs/idea/video/_MBvQZsTPKONt09X.mp4 / DECO*27「テレパシ」）

ポップ・コミック調のキネティックタイポグラフィ映像。20.8秒、1920x1080、60fps。映像1（メンタルチェーンソー）が暗く攻撃的なのに対し、本映像は明るいポップ系で、別系統の文法を補う。

### 1B.1 構成（フレーム解析）
- 0–1秒: 白い輪郭線だけの「あ」が黒地で連続スクロール（ワイヤーフレーム文字の導入）。
- 1秒: 平坦な黄色地に小さく中央寄せの題名「テレパシ DECO27」。
- 2–9秒: 黄色地に極太ゴシックのピンク文字。「はあ？？」「まじで」「マジで STOP」「嫌」「あーし」など、1〜2文字の特大スマッシュ。文字は画面からはみ出し、白い影と縁取りで地から分離する。「回」「目」を四角や梯子の図形から段階的に構築する。
- 9–10秒: 完全な黒地に細い手書き風の白い欧字「アイウォンチューコール」を斜めに置く静かな転換（句読点）。
- 10–20秒: ピンクと黄色を反転させて場面転換（ピンク地に黄色文字、黄色地にピンク文字）。三角や対角のくさび形で色面を切り替える。疑似UI（破線の枠・落書き記号・音声波形・円・×記号）と、市松やハーフトーンの網点、斜めの雨状ハッチングを背景に敷く。「ザッピング」「妄想」「継承」「光」などの特大スマッシュが続く。

### 1B.2 技法カタログ（映像1に対する追加）
1. 2色の反転による場面転換: 基調2色を反転させ、対角のくさび形で切り替える。
2. 図形からの文字構築: 四角・梯子・円などの図形を組み上げて漢字を作る。
3. 疑似UIと記号の装飾: 破線の枠、落書き、音声波形、円、×記号、標識を、すべてコードで描ける図形として散らす。
4. 網点と斜線のテクスチャ: 市松・ハーフトーンの網点と斜めのハッチングを文字の背面に敷き、平坦な画面を richにする。
5. 静かな句読点の手書き: 場面の切れ目を、完全な黒地と細い手書き風の欧字で見せる（映像1の無音ブラックアウトに対し、繊細な筆致版）。
6. 極太ゴシックのはみ出しスマッシュと白影: 1〜2文字を画面からはみ出すまで拡大し、白い影と縁取りで地から分離する。

### 1B.3 本作への翻案
本作の世界観は深夜で暗いため、参考映像の明るい配色はそのまま使わない。構造（表示粒度の切替・スマッシュ・はみ出し・句読点・装飾図形）だけを取り、色と質感は発光する文字（発光マテリアルとブルーム）と、オレンジとネオンブルーの差し色へ置き換える。

### 1B.4 音響解析との突き合わせ
ffmpeg でモノラル22050HzのWAVへ変換し、ローカルの librosa で解析した（mcp-music-analysis MCP は隔離環境のプロビジョニングでハングしたため、runbook 推奨のローカル解析に切り替えた。詳細は `docs/runbooks/mcp-music-analysis.md`）。

- 長さ20.78秒。テンポ推定は事前値で二通りに割れ、約580ミリ秒（約103BPM）と約302ミリ秒（約199BPM）が出た。これは半分と倍の関係で、参考曲のため正確なテンポは確定しない。音の立ち上がり（オンセット）は71個、中央間隔は約279ミリ秒。
- 突き合わせの結論: 文字の特大スマッシュの切替（題名→はあ→まじで→マジでSTOP→逆張り→何回目→嫌→あーい）は、おおむねビート格子に乗る。「何→回→目」の段階的構築や、落書き・標識・図形の細かい動きは、オンセットに乗る。9〜13秒のブラックアウトと色面転換の区間ではビート間隔がわずかに伸縮し、静かな手書きの句読点と一致する。
- 設計への含意: 疾走感は「表示粒度の切替をビートに、細部の動きをオンセットに乗せる」ことで生まれる。本作の課題曲では、ビート格子は TextAlive 音楽地図（beatId固定）が正典であり、librosa は不要。オンセット相当の細部は声量（vocalAmplitude）の山で代替できる。

## 2. シャッターチャンス 公式MV（https://www.youtube.com/watch?v=ZVGbTFcfnn8）

3:10、**≈117.5 BPM（ビート間隔 約511ms）**。TextAlive songmap: beats=361、サビ区間=10、フレーズ=46。

### 2.1 構成の要点

- イントロ0–2sの超高速カット連打（0.1–0.3s間隔）で世界観提示 → 円形レンズマスク → タイトル（指フレームポーズ）
- Aメロ=縦組み手書き風タイポ（静）、サビ=極太ゴシック+白フチ+蛍光色の段スタック（動）の**2系統タイポ切替**
- 2番=縦型スマホUI・SNSフィード全画面（「アーカイブ」歌詞と同期）
- ラスサビ前(2:30–2:34)が最大の山: 写真カードのタイル増殖→**本物のカメラUI（フレームガイド+赤●REC+フォーカス十字）**→モザイク→ドン
- アウトロはイントロの決めポーズに回帰する**ループ構造**

### 2.2 スタイル

- 配色: パステル青×黄の2色基調（#AEC6F0 / #FBE6A2系）+白フチ、アクセントに桃ピンク♡
- モチーフ: 指フレーム、円形レンズ、ポラロイド/写真カード、SNSフィード、紙吹雪/破片トランジション、カメラUI
- キャラ: ミク&リンの**白フチ切り抜きステッカー風**配置（素材をモーショングラフィックスで動かす流儀）

### 2.3 リリックアプリへの借用候補

ファインダーUI常時表示 / クリック=シャッター（フラッシュ+撮った瞬間の歌詞が写真カード化して画面端にスタック）/ 「ピント合わせて」=モザイク→解像の文字演出（`unit.progress`+`Ease`）/ サビで青黄2分割 / 破片トランジション / 曲終わりに撮影アルバム一覧表示。

## 3. the hole / 足立レイ, r-906（https://www.youtube.com/watch?v=qe29NgNqJZw）

3:56、**≈117.5 BPM** — シャッターチャンスと同テンポ帯のため、音ハメ技法をほぼ等倍のリズム感覚で移植可能。

### 3.1 音ハメの核

概要欄のサンプル明細（ビーム.wav×310、心音.wav×104、シンバル×56、正弦波277Hz×128）が示す通り**1音1カット級の高密度音ハメ**。「付加的な音楽表現」の最重要参考。

- ビート復帰の瞬間に色（オレンジ液体）が噴出 / 強拍で全画面極太タイポ「MORE」+赤フラッシュ
- 連打音=キャラ複製増殖・縦スライス高速明滅 / ブレイク=完全ブラックフレーム1–数コマの句読点
- 心音=黒く潰れた破損キャラの痙攣（グリッチ振動）

### 3.2 スタイルとWebアプリ応用（実装難度付き）

白/オフホワイト×黒主線のミニマル2色+クライマックスのみ赤/オレンジ差し色。素材はフラット線画+疑似UI（偽ニュース速報）。

- 【低】白地黒文字ミニマル基調+サビのみ差し色フラッシュ / ビート同期フルスクリーン極太タイポ / 句読点ブラックアウト / 注釈オーバーレイ（✕記号・矢印・短英文）
- 【中】縦スプリット○✕対比（`findBeatChange`）/ 文字複製タイリング明滅 / 回転飛翔テキスト / 左右対称スピーカー図形+`getVocalAmplitude`脈動
- 【中–高】疑似UIレイヤー（自作ダミーUIなら権利問題なし）
- 【高】文字グリッチ（矩形スライスずらし+RGBずれ、WebGL）

## 4. 横断的知見（ブレスト用サマリー)

1. **疾走感=ビート粒度の演出切替**。3素材とも「1拍単位で何かが必ず動く」が、粒度（文字/単語/フレーズ/画面全体）を数拍ごとに切り替えて単調さを回避している
2. **シャッターチャンス(117.5 BPM)のビート間隔511msは、リズム操作が最も気持ち良い帯域**。the holeと同テンポなので音ハメ文法を直輸入できる
3. **色は2色基調+差し色1色**が3素材共通。テキスト主体でも画面が痩せない
4. **句読点としての完全黒/完全白フレーム**は1コマで効く最安の音ハメ
5. AI生成素材なしでも、(a)文字グリフ変形 (b)図形・記号 (c)自作疑似UI (d)強ボカシ背景 で画面は十分リッチにできる
