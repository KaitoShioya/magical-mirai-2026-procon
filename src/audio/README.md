# audio — 操作音

- **責務**: Web Audio による操作音。どのレーンを叩いても同じ単一の「水滴が弾ける音」を鳴らす（`droplet.ts`）。`AudioContext.currentTime` を使う発音の予約。較正用の基準音も鳴らす。
- **禁止依存**: ゲームの時計（再生位置）と音声出力の時計（`AudioContext.currentTime`）を混同しない。`profiles`・`tools` を import しない。
- **担当Issue**: #52・#53
- 詳細は `docs/decisions/architecture.md` を参照する。

## 公開窓口（`index.ts`）

- `createOperationSoundEngine()` — 操作音エンジンを生成する。
- `OperationSoundEngine` 型・`EngineContextState` 型。

エンジンの契約（`types.ts`）:

- `unlock(): Promise<EngineContextState>` — 利用者操作中に呼び、AudioContext を生成・起動する。冪等。失敗時はキャッシュを消し再試行可能にする。
- `setEnabled(enabled)` — 操作音の有効・無効。無効のあいだ発音は無音。
- `setDeployTimbre(active)` — 投下中かどうか。真のあいだ、以後の発音を少し大きく・存在感を増す。既定は偽。鳴っている音は再調整しない。呼び出し側（#59）は投下の開始で真、投下窓の終了で偽へ必ず同期させる（状態の消し忘れによる音色の残留を防ぐ）。
- `playSlot(slotIndex)` — レーン番号を範囲だけ検査し、どのレーンでも同じ水滴音を即座に発音する（音色はレーン番号で変えない）。未起動・無効・範囲外は無音。
- `playCalibrationCue()` — 較正用の固定の短い基準音を鳴らす。操作音の有効・無効に関わらず鳴る（較正は設定の準備手順のため）。
- `soundingVoiceCount` — 発音中（奪取の対象）の数。常に上限以下。
- `activeVoiceCount` — 接続中（発音中と消音中の合計）の数。一斉奪取で一時的に上限を超え得るが減衰後に0へ戻る。
- `contextState` — AudioContext の状態（`"uninitialized"` を含む）。
- `dispose()` — 後始末。

## 責務境界

- 単一の水滴音の合成（上向きにチャープする気泡サイン・着水の衝撃の短い帯域制限雑音・成分ごとの音量包絡・タップごとの個体差）は `droplet.ts` が持つ。AI生成音源や権利のあるサンプル録音は組み込まず、すべて Web Audio のコード合成で生成する。音はどのレーンでも同じにし（利用者の決定）、高域は帯域制限で和らげて少々の遅延でも違和感を小さくする。
- 投下中は、水滴音を少し大きく・存在感を増す（`setDeployTimbre(true)` のあいだ）。投下中に新しく鳴らす音にのみ適用し、すでに鳴っている音は遡って書き換えない（投下を時間幅の状態として扱う）。
- 操作音のOFF操作を載せる設定画面は **Issue #77** が担う。本サブシステムは `setEnabled` の口を用意するに留める。
- タップ入力の取得（#47）・タップ判定（#48）・通しプレイの結線（#59）は本サブシステムの外であり、発音の公開契約を提供するに留める。

## 受け入れ診断

- `audio.html`（入口 `diagnostics/main.ts`）— 画面の縦方向を7レーンに分割し、タップした高さでレーンを選んで、どのレーンでも同じ水滴音を発音する。「投下 ON/OFF」で投下中の音色（少し大きく・存在感を増す）、「較正音」で較正用の基準音、「操作音 OFF/ON」で有効・無効を試聴できる。本番配信には含めない。
- `scripts/audio-smoke.mjs`（`npm run smoke:audio`）— 起動前は無音、信頼された入力で `running` へ到達、16音同時で発音中16、30音同時で上限24以下に保たれ減衰後に0へ収束、をヘッドレスで確認する。加えて、共有出力グラフを通したオフライン描画で、多数同時（同時発音上限ぶん）でクリップしないこと・直流の偏りが小さいことを確認し、単音の最大振幅と二乗平均平方根を記録する。較正音が操作音の有効・無効に関わらず鳴ることも確認する。
