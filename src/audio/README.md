# audio — 操作音

- **責務**: Web Audio による操作音。コードトーン格子（その瞬間の和音の構成音をY軸へ割り当てる）と、`AudioContext.currentTime` を使う発音の予約。
- **禁止依存**: ゲームの時計（再生位置）と音声出力の時計（`AudioContext.currentTime`）を混同しない。`profiles`・`tools` を import しない。
- **担当Issue**: #52・#53
- 詳細は `docs/decisions/architecture.md` を参照する。

## 公開窓口（`index.ts`）

- `createOperationSoundEngine()` — 操作音エンジンを生成する。
- `OperationSoundEngine` 型・`EngineContextState` 型。

エンジンの契約（`types.ts`）:

- `unlock(): Promise<EngineContextState>` — 利用者操作中に呼び、AudioContext を生成・起動する。冪等。失敗時はキャッシュを消し再試行可能にする。
- `setEnabled(enabled)` — 操作音の有効・無効。無効のあいだ発音は無音。
- `setDeployTimbre(active)` — 投下中かどうか。真のあいだ、以後の発音に明るい倍音層（基本周波数の2倍の正弦波）を重ねる。既定は偽。鳴っている音は再調整しない。呼び出し側（#59）は投下の開始で真、投下窓の終了で偽へ必ず同期させる（状態の消し忘れによる音色の残留を防ぐ）。
- `setSlotPitches(midiNotes)` — 各Y軸スロットの音高（低い順）を設定する。未設定・非有限値は無効化する。
- `playSlot(slotIndex)` / `playNote(midiNote)` — 即座に発音する。未起動・無効・範囲外は無音。
- `soundingVoiceCount` — 発音中（奪取の対象）の数。常に上限以下。
- `activeVoiceCount` — 接続中（発音中と消音中の合計）の数。一斉奪取で一時的に上限を超え得るが減衰後に0へ戻る。
- `contextState` — AudioContext の状態（`"uninitialized"` を含む）。
- `dispose()` — 後始末。

## 責務境界

- 和音名（"Fm" 等）から音高集合への変換、3〜4和音を2オクターブへ展開して7スロットを埋める規則、どのオクターブに置くかの音域配置は **Issue #35・#36** が担う。本サブシステムは割り当て済みの音高配列を `setSlotPitches` で受け取るだけにする。
- 投下時の倍音追加（明るい倍音を1層重ねる）は **Issue #53** で実装済み。`setDeployTimbre(true)` のあいだ、発音は基本音（三角波）に加えて基本周波数の2倍の正弦波を一定比率で重ねる。基本周波数は変えないため協和を崩さず、基本音より上に成分が増えるため音色が明るくなる。投下中に新しく鳴らす音にのみ重ね、すでに鳴っている音は遡って書き換えない（投下を時間幅の状態として扱う）。倍音は基本音と同じ音量包絡で駆動し、別の立ち上がり雑音を出さない。
- ノーツ音の高品質化（楽曲に合った楽器音への差し替え）は **Issue #169** が担う。最小実装の三角波を、ドラム・ベース等の楽器音や打ち込み音楽制作のような心地よい音へ、コードによる合成（加算合成・周波数変調合成・減算合成・打楽器合成など）で差し替える。AI生成音源や権利のあるサンプル録音は組み込まず、すべて Web Audio による合成で生成する。本サブシステムの仕組み（コードトーン格子・同時発音管理・起動・有効無効）を流用する。
- 操作音のOFF操作を載せる設定画面は **Issue #77** が担う。本サブシステムは `setEnabled` の口を用意するに留める。
- タップ入力の取得（#47）・タップ判定（#48）・通しプレイの結線（#59）は本サブシステムの外であり、発音の公開契約を提供するに留める。

## 受け入れ診断

- `audio.html`（入口 `diagnostics/main.ts`）— 画面の縦方向を7スロットに分割し、タップした高さでスロットを選んで発音する。診断専用の固定サンプル和音（ファのナチュラルマイナー）で音程の聞き分けを実演する。「投下 ON/OFF」ボタンで投下中の音色（倍音層を重ねる）を切り替え、明るく・厚くなり音程は変わらないことを試聴できる。本番配信には含めない。
- `scripts/audio-smoke.mjs`（`npm run smoke:audio`）— 起動前は無音、信頼された入力で `running` へ到達、16音同時で発音中16、30音同時で上限24以下に保たれ減衰後に0へ収束、をヘッドレスで確認する。加えて、共有出力グラフを通したオフライン描画で通常時と投下時の周波数重心を測り、投下時が通常時の1.05倍を超えて高い（明るく聞こえる）ことを確認する。
