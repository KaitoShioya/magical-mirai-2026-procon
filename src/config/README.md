# config — 定数・調整値と楽曲ロード設定

- **責務**: 定数・調整値と楽曲ロード設定。`songs.ts`（6曲のURLと音楽地図ID。本Issueで作成済み）と、`tuning.ts`（楽曲非依存で複数のサブシステムが横断参照する調整値。Issue #6 で作成）。
- **禁止依存**: 描画・判定などの論理を持たない（値の定義のみ）。
- **担当Issue**: `songs.ts` は #1（最小）/ #5（拡張）、`tuning.ts` は #6

## `tuning.ts` に置く値の境界

`tuning.ts` には、楽曲が変わっても同じ値であり、複数のサブシステムが横断的に参照する調整値だけを置く（判定窓・音程スロット数・タップ総数上限の比率・ゲージ蓄積の倍率・タップ対象の最小サイズ）。次の値は `tuning.ts` に置かない。

- **楽曲によって変わる絶対値**は曲プロファイル（#34・#46）と譜面（#38・#39・#44）に置く。1拍の長さと毎分の拍数、フルに可能なタップ数、タップ総数上限の絶対値、見せ場の数と重み、セクションごとの密度、同時に押す和音の数、量子化の絶対値、満タンゲージの絶対タップ数などが該当する（出典 `docs/decisions/architecture.md` §3.6・§5）。
- **単一の所有モジュールが定まる値**は、その所有モジュールが定義する。得点合成の基準値（多様性係数・投下倍率・コンボの上限割合）は scoring（#55・#56）、ランクの段階は scoring（#55）と `src/types/`、ウォームアップのカウントダウンは screens（#2）、性能閾値は rendering（#18）が所有する（出典 `docs/decisions/architecture.md` §4・§3.8）。
- **原典に単一の確定値の記載がない値**は推測で埋めず、所有Issueが確定する。

詳細は `docs/decisions/architecture.md` を参照する。
