# ui — 得点系の値の文書要素

- **責務**: 得点系の値を文書要素で表示する。プレイ中は画面四隅の操作情報（得点・コンボ・ゲージ・ランクの百分位）を切り欠きを避ける安全領域に重ねる。結果時は自己ベストと成長履歴（`scoreHistoryView.ts`、Issue #67）を表示する。
- **禁止依存**: 判定・得点の論理を持たない（値を表示するだけ）。`profiles`・`tools` を import しない。描画器の層に依存しないため `rendering`・`three` も import しない（保存層が読み出した値の型だけを `scoring` から取り込む）。
- **担当Issue**: マイルストーンM5（自己ベスト・成長履歴の表示は #67）。
- 詳細は `docs/decisions/architecture.md` を参照する。
