# utils — 純粋関数

- **責務**: 副作用のない純粋な補助関数。破棄の木構造走査（dispose）、数値計算、イベントの仲介など。
  - **カメラ軌跡評価器 `cameraTrajectory.ts`（#13）**: カメラキーフレーム列から、任意時刻の位置と注視点・軌跡上速度・軌跡上距離と時刻の相互変換を返す。描画（#40）と判定（#48・#49）が共有する。
  - **拍同期スケジューラ `beatScheduler.ts`（#16）**: 拍の開始時刻の昇順配列を読み、描画フレームごとに、直前に処理した時刻から現在時刻までに跨いだ拍を時刻の昇順で1回ずつ通知する。渡す時刻はゲームの時計（再生位置のミリ秒）で、再生位置の飛び（シーク・再同期・タブ復帰）では advance ではなく syncTo で基準を貼り直す（本編結線 #59 が担う）。視覚演出（#17・#76・#23）が拍に同期して発火するための共通基盤。
  - **和音名→音高集合パーサー `chordPitch.ts`（#35）**: TextAlive が文字列で提供する和音名を、構成音を2オクターブ展開したMIDIノート番号の昇順集合へ変換する。根音・品質・分数和音の低音を構造化して返し、JUST音程7スロット生成（#36）と無和音区間処理（#37）が再利用する。無和音 "N" は音高化せず例外とし、N.C. の解決は #37 が担う。
  - **画面拡大・減衰揺れ評価器 `screenShake.ts`（#76）**: 拍の発火・現在時刻・画面寸法から、画面空間の相似変換（倍率と画素移動）を返す。拡大は最大値更新で長い余韻を、揺れは最新拍で短い衝撃を持ち、揺れの移動量は拡大の画面外余白の内側に収まる。小節頭判定（拍位置の減少検出）・拍ごとの拡大量配列の前計算・操作同期の逆変換関数も提供する。描画基盤（`rendering` の `setScreenTransform`）が変換を canvas へ当て、統括（`app`）と診断（`rendering/diagnostics/screenShake`）が拍を供給する。
  - **較正補正値推定器 `calibrationOffset.ts`（#50）**: 一定周期で表示した点滅の実表示時刻列と利用者のタップ時刻列から、入力の遅れの補正値（ミリ秒）の初期値を推定する。各タップを最近傍の点滅へ対応付け、点滅ごとに最も近い1タップへ集約し、外れ値を除いた差分の中央値を返す。較正UI（`src/app/calibration`）が初期つまみ位置に使い、最終値は確認段階の手動微調整で定める。
- **禁止依存**: 特定のサブシステム（`rendering`・`engine` 等）に依存しない。`tools` を import しない。`src/profiles/schema` を取り込まない（判定層が評価器経由で曲プロファイル型へ間接依存しないよう、入力型は自前で定義する）。
- **three.js への依存**: 数値計算で曲線が必要な場合は three.js の曲線部品（`CatmullRomCurve3`・`Vector3`）を名前付きで取り込んでよい（技術要件が `CatmullRomCurve3` を指定するため。自前再実装より検証済みの標準実装を使う）。
